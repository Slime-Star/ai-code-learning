# 慧编云管理端

启动项目后，打开 http://localhost:5173/login ，使用管理员账号登录，会自动进入 `/admin`。管理员账号由本机工具或另一位管理员创建，公开注册页只允许注册学生和教师。

## 可用功能

- 数据总览：累计及今日运行次数、成功与失败次数、成功率、7/14/30天趋势、语言分布、活跃用户及各模块记录数量。统计采用北京时间，来自已保存的全站数据。
- 账号管理：新建账号、修改资料和角色、重置密码、查看并注销登录会话。修改角色或密码会使该账号的现有登录失效。
- 教学管理：班级、成员、教师题目、测试、题目配置、报名及提交评分。班级转交会一并转交题目；涉及现有测试时会提示先处理题目归属。
- 内容管理：课程与视频地址、每日练习题库、MySQL资源库、论坛帖子、评论和点赞。
- 学习与积分：运行明细、打卡和练习进度、签到、答案解锁、商品库存、兑换记录和积分调整。
- 消息与社交：站内会话、成员、消息、好友和申请。
- 数据表支持搜索、分页、详情和 CSV 导出。可维护的字段提供编辑入口；删除前显示关联影响，需要明确确认。管理操作记录可查询和导出。

## 数据与操作说明

- 课程、练习和新论坛内容由主服务统一存储，管理端保存后，其他用户重新加载对应页面即可读取最新内容。课程中默认封面可填写 `html.jpg`、`python.jpg` 等已有图片名，也可填写图片网址。
- 旧版论坛数据曾经仅存在各自浏览器，主服务无法读取其他电脑的浏览器。原作者打开论坛后，可点击“导入旧帖子”把自己的旧帖同步到平台；导入会去重，保留原浏览器数据。
- 课程卡片原有的学习人数和下载次数是历史展示值；管理总览的运行次数、用户数量等按数据库实际记录计算。
- 用户删除会删除预览中列出的学习和社交数据。仍拥有班级、题目、测试的教师，需要先转交或删除所属内容。自己的管理员账号和最后一个管理员账号受保护。
- 签到和积分金额保留原始记录。更正积分请新建一笔积分流水，正数增加、负数扣除；余额不能低于零。兑换记录的状态为 `pending`（待发货）或 `completed`（已完成），删除兑换记录不会自动退款或恢复库存。
- 删除课程保留既有运行历史；删除商品保留兑换快照；删除测试会同时删除对应题目配置、报名与提交；删除运行记录会重新影响总览与排行榜统计。已删除的默认内容不会在服务重启后恢复。
- 管理端不显示密码哈希、盐值或登录令牌。普通账号即使修改浏览器里的角色，也无法通过服务端权限检查。

## 本机创建或重置管理员

在 `code-runner-server` 目录执行：

```powershell
python manage_admin.py 新管理员用户名
python manage_admin.py 新管理员用户名 --generate
python manage_admin.py 已有管理员用户名 --reset
```

第一条通过隐藏输入设置密码；第二条生成随机密码并只在当前终端显示；第三条重置已有管理员密码并注销其登录。工具不会覆盖同名学生或教师账号。管理员初始登录信息不保存在本说明中。

## 验证

```powershell
# code-runner-server 中执行
python -m unittest test_admin_api.py test_wrong_questions.py test_interactive_runner.py -v

# server 中执行
node test_resource_admin.js

# ai-code-learning 中执行；需要本机 Playwright/Chrome
node artifacts/console-qa/admin-smoke.cjs
npm run build -- --outDir artifacts/admin-build
```

浏览器和 Python 集成测试使用独立测试数据库，不修改实际用户数据。项目同时需要主服务（3002）、资源服务及 MySQL（3001）、AI服务（3000）和前端（5173）。
